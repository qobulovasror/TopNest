How installation works

TopNest is currently in private developer preview. These links work for testers with TopNest 0.5.0 or later.

  1. Install TopNest and open it once.
  2. Choose an extension and click “Open in TopNest.” Your browser may ask to open the app.
  3. TopNest checks the package, shows the HTTPS host, and waits for your confirmation.

Prefer a file? Download the JSON package and use TopNest → Settings → Extensions → Import package file.
